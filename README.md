#           🍷 Vinharia Agnello

<!-- Descrição da vinharia -->
É uma empresa familiar de São Paulo especializada na venda de vinhos. Com a mudança dos hábitos de consumo, a empresa busca ampliar sua presença digital por meio de um e-commerce, mantendo o atendimento personalizado e facilitando a escolha dos produtos pelos clientes.

## 🎯 Objetivo

Criar um site organizado para apresentar a Vinheria Agnello, seus produtos, sua história e formas de contato.


## 📄 Páginas do projeto

- Início (index.html) : Apresentação
- História : Informações sobre a empresa e sua trajetória.
- Produtos: Apresentação dos principais tipos de vinhos.
- Galeria : Imagens dos vinhos.
- Contato : Formulário para contato.

 ## 🔨Ferramentas utilizadas
- Classes e IDs em CSS
- Estrutura semântica HTML5
- Formulário de contato
- Headings e parágrafos
- Imagens;
- Layout 
- Listas
- Tabela HTML
- Vídeo
- Links internos e externos
- Menu de navegação
